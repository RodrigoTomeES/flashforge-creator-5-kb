# **Creator5 Update log** [\[wiki §\]](https://wiki.flashforge.com/en/creator-series/creator-5-series/manual/firmware-release-history#creator5-update-log)

**Creator5-1.9.9-1.3.0-20260907**

1\. Important notice: After upgrading, this version cannot be rolled back to V1.9.8 or earlier versions via online or USB drive. Downgrading may result in unknown errors.

2.Added support for exFAT and NTFS USB flash drives.

3.Added the Skip Object feature in the app. Requires updating Flash Studio Mobile to version 1.13.0 or later.

4.Added recognition of nozzle information from 3mf files in the local file list.

5.Added support for 5 filament types: BVOH, ASA-CF, ASA-GF, ABS-GF, and PPA-CF.

6.Added support for connecting to hidden Wi-Fi networks by manually entering the SSID.

7.Added support for viewing license information in Settings.

8.Improved Wi-Fi connection stability and fixed the offline display issue in the app and slicing software. It is recommended to update Flash Studio Desktop and Flash Studio Mobile to the latest versions.

9.Optimized purge filament handling.

10.Optimized heating power control.

11.Improved print quality at low layer heights (0.08 mm, 0.10 mm, and 0.12 mm) with enhanced first layer adhesion.

12.Improved startup safety protection to prevent unintended nozzle heating after startup.

13.Optimized screen-off behavior to automatically turn off the screen backlight when the screen is off.

14\. Fixed the issue where time-lapse videos could not be generated when the model file name contains spaces or special characters.

15\. Fixed other known issues.

**Creator5\_library\_1.9.4**

**Creator5-1.9.4-1.2.6-20260702**

**Creator5-1.9.3-1.2.5-20260615**

5\. Fix other known bugs.

 2.Optimize Startup Wizard.

3\. Fix the issue that Flash Studio stays offline after recovery from prolonged network outage.

4\. Improve reliability to resolve occasional USB drive upgrade failures.

5\. Update the QR code on the after-sales guide.

7\. Fix other known bugs.
